Sobre o Projeto

Este projeto foi desenvolvido para o Programa Agrinho, na categoria Programação, com o objetivo de apresentar informações sobre a importância da sustentabilidade ambiental e do agronegócio sustentável.

A página web aborda temas relacionados à preservação do meio ambiente, ao uso consciente dos recursos naturais e às práticas agrícolas responsáveis, destacando como o agro pode contribuir para um futuro mais sustentável.

Funcionalidades
Página responsiva para computadores e dispositivos móveis;
Menu de navegação entre seções;
Informações sobre sustentabilidade ambiental;
Conteúdo sobre o agro sustentável;
Destaque para ações sustentáveis;
Apresentação dos benefícios da sustentabilidade;
Layout moderno utilizando HTML e CSS.
Tecnologias Utilizadas
HTML5
CSS3
Objetivo

Conscientizar os visitantes sobre a importância da sustentabilidade e demonstrar que a produção agrícola pode caminhar junto com a preservação ambiental, contribuindo para o desenvolvimento sustentável da sociedade.

Projeto desenvolvido por Rafael Baran para o Projeto Agrinho Programação, sob orientação da professora Regiane Heil Plem.
